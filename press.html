  • Sequência ordenada de elementos do mesmo tipo;

  • É a estrutura mais básica do R: um valor sozinho já é um vetor de tamanho 1;

Criando funções: por quê?

  • Copiou e colou o mesmo código pela terceira vez? É hora de escrever uma função;

  • Menos repetição, menos erros: a correção é feita em um lugar só;

  • Um bom nome documenta o código: conteudo_gc(sequencia) se explica sozinho;

  • É o primeiro passo da automatização: a mesma análise para 1 ou para 10.000 sequências;

# calcula o conteúdo GC (em %) de uma sequência de DNA
1conteudo_gc <- function(sequencia) {
2  bases <- strsplit(toupper(sequencia), "")[[1]]
  gc <- mean(bases %in% c("G", "C")) * 100
3  round(gc, 1)
}

Reverso complementar

reverso_complementar <- function(sequencia) {
  bases <- strsplit(toupper(sequencia), "")[[1]]     # separa as bases
  invertida <- paste(rev(bases), collapse = "")      # inverte a ordem e cola de volta
  chartr("ATGC", "TACG", invertida)                  # troca cada base pelo seu par
}

reverso_complementar(reverso_complementar(seq_dna)) == seq_dna    # um bom teste!

Tm de um primer

  • A regra de Wallace, para oligos curtos: \(Tm = 2 × (A + T) + 4 × (G + C)\);
tm_wallace <- function(primer) {
  bases <- strsplit(toupper(primer), "")[[1]]
  n_at <- sum(bases %in% c("A", "T"))      # quantas bases A ou T
  n_gc <- sum(bases %in% c("G", "C"))      # quantas bases G ou C
  2 * n_at + 4 * n_gc
}

Funções que tomam decisões: if e else

  • Por convenção, Wallace vale até 13 nt; para primers mais longos, usa-se outra fórmula;
tm_primer <- function(primer) {
  bases <- strsplit(toupper(primer), "")[[1]]
  n <- length(bases)                       # tamanho do primer
  n_gc <- sum(bases %in% c("G", "C"))      # quantas bases G ou C
  if (n < 14) {
    tm <- 2 * (n - n_gc) + 4 * n_gc        # regra de Wallace
  } else {
    tm <- 64.9 + 41 * (n_gc - 16.4) / n    # fórmula para primers mais longos
  }
  round(tm, 1)
}

Receita para escrever uma função

  1. Resolva o problema para um caso, passo a passo;

  2. Identifique o que muda de um caso para outro: esses são os argumentos;

  3. Embrulhe os passos em function() e dê um nome que diga o que ela faz;

  4. Teste com casos em que você já sabe a resposta;

  5. Aplique a muitos casos com sapply();
